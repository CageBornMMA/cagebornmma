# CageBornMMA — Where Fighters Are Made

**Forged in sweat. Proven in combat.**

CageBornMMA is a combat sports clothing and gear brand built for fighters, by fighters.  
This repository contains a simple static website (HTML + CSS) ready for GitHub Pages deployment.

## Files
- `index.html` — Homepage
- `about.html` — Brand story & values
- `shop.html` — Product listings (placeholders + images)
- `contact.html` — Socials and contact info
- `styles.css` — Site styles
- `favicon.ico` — Browser favicon
- `hero-shirt.jpg`, `pattern-shirt.jpg` — Image assets

## Deploy
1. Create a GitHub repository named `cagebornmma`
2. Upload all files from this pack to the repository root
3. Enable GitHub Pages in **Settings → Pages** using branch `main` and folder `/ (root)`
4. After a minute your site will be live at `https://<your-username>.github.io/cagebornmma/`

## Notes
- This is a static site (no backend/cart). Use Stripe/Shopify integration later for payments.
- Replace the Instagram link and social handles as required.
